Jawaban NO 1 : Bootstrap adalah framework CSS yang digunakan untuk membuat tampilan website dengan lebih mudah dan cepat. Bootstrap menyediakan komponen siap pakai seperti tombol, navbar, form, dan grid agar website terlihat rapi serta responsif.
Jawaban NO 2 : CDN: Menghubungkan Bootstrap melalui URL CSS dan JavaScript.
Download: Mengunduh file Bootstrap dan menyimpannya di folder proyek.
NPM: Memasang Bootstrap melalui Node Package Manager.
Package manager lainnya: Menggunakan pengelola paket yang mendukung Bootstrap
Jawaban NO 3 : Grid adalah sistem kolom Bootstrap yang digunakan untuk mengatur tata letak halaman website.
Breakpoint adalah batas ukuran layar yang digunakan untuk menyesuaikan tampilan website pada perangkat berbeda.
Jawaban NO 4 : container : Membatasi dan mengatur lebar konten.
row	: Membuat baris pada sistem grid.
col	: Membuat kolom pada grid.
btn	: Membuat tombol.
navbar : Membuat navigasi website.
form-control : Mengatur tampilan input form.
shadow : Memberikan bayangan pada elemen.
text-center : Membuat teks rata tengah.
Jawaban NO 5 : Class img-fluid membuat gambar memiliki lebar maksimal 100% dari elemen induknya dan tinggi otomatis agar proporsinya tetap terjaga.
